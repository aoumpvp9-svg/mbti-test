# 🔮 나의 숨은 MBTI 찾기 테스트 ✨

일상 속 12가지 상황 질문을 통해 나의 숨겨진 진짜 성향과 찰떡궁합 짝꿍을 찾아보는 인터랙티브 MBTI 성격 유형 테스트 웹 애플리케이션입니다.

---

## 🌟 주요 특징

- **12문항 스피드 테스트**: 일상 속 친근한 상황 질문으로 부담 없이 진행
- **인터랙티브 UI & 애니메이션**:
  - 부드러운 카드 전환 및 진행률 게이지 표시
  - 결과 화면 시 화려한 컨페티(꽃가루) 축하 효과
- **16가지 MBTI 상세 분석**:
  - 성격 특징 및 매력 포인트 키워드 태그
  - 최고의 궁합 & 주의해야 할 케미 안내
- **공유 & 다시하기 기능**:
  - 결과 링크 클립보드 복사 및 카카오톡/SNS 공유 지원
  - 테스트 다시 하기 기능

---

## 🛠️ 기술 스택

- **HTML5** (웹 접근성 및 시맨틱 마크업)
- **CSS3** (반응형 모바일 퍼스트 레이아웃, 글래스모피즘, 커스텀 애니메이션)
- **JavaScript (Vanilla ES6+)** (상태 관리, 결과 산출 알고리즘, Canvas Confetti)
- **웹 폰트**: Pretendard, Jua, Outfit

## 📁 프로젝트 구조

```plaintext

│   ├── app.js        # 메인 애플리케이션 상태 제어 및 인터랙션

│   └── data.js       # 12문항 질문 데이터 및 16가지 MBTI 결과 데이터
├── .gitignore        # Git 제외 파일 목록
└── README.md         # 프로젝트 소개 문서
```

## 🚀 실행 방법

별도의 서버 설치 없이 브라우저에서 `index.html` 파일을 더블 클릭하여 바로 실행할 수 있습니다.
또는 VS Code의 `Live Server` 확장을 통해 로컬 서버로 실행할 수도 있습니다.
